# 📊 2026 内审看板 - 使用说明

## 🚀 快速开始

### 方式一：双击启动（推荐）

1. **首次使用**：双击 `setup.bat` 安装依赖（只需一次）
2. **之后每次**：双击 `run.bat` 启动看板
3. 浏览器会自动打开 http://localhost:8501

### 方式二：命令行启动

```powershell
# 首次安装
.\setup.bat

# 启动看板
.\run.bat
```

## 📋 系统要求

- **操作系统**：Windows 10/11
- **Python**：3.10 或更高版本（如未安装，setup.bat 会提示下载链接）
- **内存**：至少 2GB 可用内存

## 📊 看板功能

### 五个视图页面

1. **📈 总览仪表板** - KPI 指标、审核进度、发现项分布
2. **📋 审核进度** - 甘特图、计划表、完成状态
3. **🔍 发现项分析** - 按部门统计、问题类型分布
4. **⏱️ 整改时效** - 整改天数统计、效率对比
5. **📝 开放问题清单** - 未关闭问题详情、逾期标记

### 动态筛选

- 侧边栏可选择 **审核场次** 进行筛选
- 支持多选/全选/清除
- 所有图表和数据表联动更新

## 🔄 更新数据

### 方法一：替换数据文件

1. 将新的 Excel 文件复制到 `data/` 文件夹
2. 文件名保持不变：
   - `2026 Audit Planning_V1_20260821.xlsx`
   - `2026年内审发现跟进表.xlsx`
3. 刷新浏览器即可看到更新

### 方法二：通过界面上传

1. 点击侧边栏 **"📁 上传文件"**
2. 选择文件类型（审核计划表 / 发现项跟进表）
3. 上传新的 Excel 文件
4. 数据会自动更新

## ❓ 常见问题

**Q: 启动后浏览器没有自动打开？**
A: 手动打开 http://localhost:8501 即可

**Q: 提示 "Permission denied"？**
A: 程序会自动处理，如果仍有问题，请关闭可能占用 Excel 文件的程序（如 Excel）

**Q: 如何关闭看板？**
A: 关闭终端窗口，或在终端按 Ctrl+C

**Q: 数据更新了但看板没变？**
A: 点击侧边栏 **"🔄 刷新数据"** 按钮，或按浏览器刷新键
